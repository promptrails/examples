# JavaScript/TypeScript Examples

## Prerequisites

```bash
cd javascript
npm install
export PROMPTRAILS_API_KEY="pr_key_..."
```

## Running

```bash
node javascript/basic/main.mjs
node javascript/agents/main.mjs
node javascript/chat/main.mjs
# ... etc
```

## Examples

| Folder | Description |
|--------|-------------|
| [basic/](basic/) | Client setup, error handling |
